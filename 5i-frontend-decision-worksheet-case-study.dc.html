User Workflow

For each persona, note the devices they use, tell the story of their trip through the app in plain words, then write that same trip as shorthand page flows (page → page). The Contractor persona is filled in as an example, and the Homeowner is left blank for you to fill in. This is another way of visualizing the navigation. There is no one right answer, so use your knowledge of the user stories and the example to fill in the Homeowner persona.

02

Project Decisions

Each decision comes with a definition and a few options to weigh. Think about what you would use for Renovation Revolution. The most common choice as of 2026 is already selected, but pick or write what is best for your team. Save this worksheet, and it can help you plan future projects.

◇ AI Prompt
"You are a senior frontend engineer helping me choose the architecture for [project description]. [number of engineers, time to MVP]. For each decision I name (I will paste the list), give me two or three realistic options. For each option, list the pros, the cons, and the team size or timeline it suits. Then recommend one option for this project in a sentence and name the biggest risk of picking it. Keep each decision to a short table."
03

Page Decisions

With the project decisions settled, you can work through each page. This worksheet lists every page decision that needs to be made. You don't have to write it all out for each page, but it is worth doing once to get in the flow of making these decisions. I have included an example for each one based on the case study.
