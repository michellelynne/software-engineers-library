Search & Filters

Renovation Revolution

The way people search shapes the system behind it. Like a user story, every search says who is looking, what they want to find, and how they want it narrowed down. Each filter and sort names a field that has to be stored and searchable, so mapping searches first tells you which tables, keys, and indexes you need to return results quickly and accurately.
