API

Renovation Revolution

One project can have multiple APIs, so it is helpful to keep the logic in the service layer. For this worksheet, pick one API type to get practice with it. Below is the same Contractor Profile example written three ways so you can compare, then choose. Aim to return data the client can display as-is, so the same call works across web and mobile. Then stay flexible. Once it is live, see how people are using it, and tune the endpoints toward what they reach for most.

EX

One example, three API types

The Contractor Profile page needs to create a profile and fetch a profile. Here is that same functionality in each style.

Profile datawhat a contractor profile holds
•
Contractor or company name
•
Email and phone number — with contact preferences
•
Description of services available — as structured categories, not free text
•
Photos of previous jobs
•
Customer reviews of previous jobs
•
Current availability
Avoid unstructured data where you can. When comparing contractors, customers need a clear idea of what each can do. It can be extra confusing if contractors use words they don’t understand. With structured data, the app can provide clear definitions where necessary.

GraphQLone call, client picks fields
mutation {
  createContractor(input: {
    name: "Sunrise Contracting Co.",
    email: "hello@sunrisecontracting.com",
    phone: "+1 (415) 555-0182",
    services: [KITCHEN_REMODEL, BATHROOM_REMODEL]
  }) { id name email }
}

query {
  contractor(id: "8f3a") {
    name
    email
    phone
    services
    availability
  }
}
gRPCfast, internal service-to-service
service ContractorService {
  rpc CreateContractorProfile (ContractorProfileRequest) returns (ContractorProfileResponse);
  rpc GetContractorProfile (GetContractorProfileRequest) returns (ContractorProfileResponse);
}

// CreateContractorProfile request
ContractorProfileRequest {
  name:     "Sunrise Contracting Co."
  email:    "hello@sunrisecontracting.com"
  phone:    "+1 (415) 555-0182"
  services: [KITCHEN_REMODEL, BATHROOM_REMODEL]
}

// GetContractorProfile request
GetContractorProfileRequest { id: "8f3a" }
