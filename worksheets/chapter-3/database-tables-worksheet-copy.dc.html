Renovation Revolution

Once you know what data to store, the next step is deciding how to structure it. Turn each object from your data model into a table. For every column, pick a type and mark whether it is a primary key that identifies the row, or a foreign key that points to another table. Here are some starter tables from the case study to fill in and build on.

PKprimary key, identifies the row
FKforeign key, points to another table
Common types: uuid, int, varchar, text, boolean, timestamp, json
