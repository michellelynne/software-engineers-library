Search & Filters

How people search your data is part of designing it. Every filter and sort points to a field that has to be stored and made searchable. For each search, write down who is looking, what they want to find, how they narrow it down, and how the results should be ordered. There is one example to get you started.

Want to see it filled in? See the Renovation Revolution example.
The pattern
As a [user], I want to find [what], filtered by [conditions], sorted by [order].
◇ AI Prompt
"Here is a search my users need: [describe who, what, filters, and sort]. What database fields and indexes would I need to support filtering and sorting it efficiently?"
