User Story to
Data Model

Data models should be inspired by the user stories. Write a user story, then list the data you would need to store to make it happen. There is one example to get you started. Instead of trying to imagine every possible option, start with the minimum. It's much easier to add data later than remove data.

Want to see it filled in? See the Renovation Revolution example.
