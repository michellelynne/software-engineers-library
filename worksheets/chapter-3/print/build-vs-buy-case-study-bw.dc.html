Build vs Buy

Renovation Revolution

For each user story, I’ve listed the technical components it requires. Do you build or buy it? Think about whether the component is a universal issue, unique to your industry, or part of your organization’s core competency. This is filled in with user stories and components from the Renovation Revolution case study.

AI Prompt
"Here is a technical component of my product: [describe it]. Are there existing vendors or open-source tools that address this issue? Should I build or buy?"
1 As a homeowner, I want to scan my room with my phone so that the application can create a 3D model of my space.
Authorization & Authentication
A well-established, universal problem with proven identity providers. Not worth building ourselves.
3D Image Capture
Outside our core competency as a construction marketplace. Better handled by an existing SDK.

2 As a homeowner, I want the application to analyze my room and provide a comprehensive list of all possible upgrades so that I can see all my renovation options in one place.
3D Image Analyzer
Requires specialized computer-vision expertise we don’t have in-house.
Datastore of renovation options
Specific to how we categorize renovation options; tailored to our own taxonomy.
Algorithm for matching an image to data
Unique matching logic tied to our own catalog; a core part of our value proposition.
Your reasoning
3 As a homeowner, I want to take a style quiz before viewing options, so the application can recommend items that fit my taste and reduce decision fatigue.
Interactive Quiz
Simple enough to write ourselves, and lets us tune questions to our own style categories.
Save results to the datastore
Standard application logic connected to our own systems.
Ability to write and modify questions
Needs to stay flexible as our style catalog grows; not worth licensing.
User profile saved with quiz results
Core to our own user data model.
Your reasoning
4 As a homeowner, I want to view upgrade options visually on the 3D model or as a list, so I can easily understand what each change would look like in my space.
3D image replacement
Best handled by the same vendor providing 3D capture and analysis.
Your reasoning
5 As a homeowner, I want to select specific items for each upgrade from a curated, style-matched list, so I am not overwhelmed by too many choices.
Algorithm for matching choices to style results
Ties directly to our proprietary style-quiz results; a differentiator worth owning.
Your reasoning

Data store connecting parts
Vendor catalogs exist for construction parts; we’ll license the data and make small tweaks ourselves.
Part taxonomy
Comes bundled with the parts catalog vendor.
