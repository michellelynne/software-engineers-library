Sacrifice

You cannot add time to the day, you can only remove something that currently uses it. Start with the total minutes you can free up, then split them between the goals.

Now split those minutes between the goals. Some goals need less time than others. If you are blocked or not ready for one, set it to zero, and change the budget as your priorities move.
