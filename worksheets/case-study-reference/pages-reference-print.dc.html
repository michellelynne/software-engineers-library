Renovation Revolution

Every page for the Renovation Revolution case study, turned from the user stories into screens on the Designer Worksheet. Keep this handy as you design the backend. To map each page to its call to action and data, use the Designer Worksheet; to review the stories behind them, see the User Stories reference.

Order & Delivery Tracking Page. Follow every order and delivery through to installation day. Used by homeowners and contractors alike.

Room Suggestions Page. Show every possible upgrade the app finds for a scanned room.

Style Quiz Page. Capture the homeowner's taste before showing options.

Order Review Page. Confirm required parts are included and nothing is incompatible.

Send to Contractor Page. Submit the final selections for the contractor to finalize.
