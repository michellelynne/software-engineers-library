Renovation Revolution

It’s time to put on your designer cap. We’re going to take the user stories and convert them into Pages for the Frontend Engineer. To keep each page focused, specify a single Call to Action for each. Then, in lieu of a wireframe, we’ll specify all the data that will appear on each Page. The examples below are filled in from Renovation Revolution.

One “Call to Action” per page. If a story starts to span multiple pages, split it so each page can hold its own information. Information can be available or derived — derived data (like a labor estimate) adds value when the algorithm behind it is well thought out.
