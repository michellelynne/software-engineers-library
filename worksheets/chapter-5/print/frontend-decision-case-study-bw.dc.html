Now you are the Senior Frontend Engineer. Before writing a line of code, you map how each persona moves through the app, then make the technical decisions that shape the whole project. The Contractor persona is filled in as an example.

01

User Workflow

Persona Contractor
Devices
As the Contractor, I am often on the road and tend to use iPhone devices to interact with applications. I am rarely able to work on a desktop.
Page Flow Story
As the contractor, I will first start with the onboarding user workflow. Then I will review the information I have provided that is visible to others on my profile page. When I am satisfied with my profile, I can start reviewing the available projects on the summary page. From there, I will select a project and can view a limited set of project information, excluding any homeowner contact information. If it looks interesting to me, I will create a bid for that contract. Once a project is awarded, I can view homeowner contact information. I can examine each room in the project in detail and suggest changes to the work or purchases, and the project details page shows the status of any suggestions I have made.
Page Flows
Contractor Onboarding Page → Contractor Profile Page Available Projects Summary Page → Project Detail Page (Pre-Contract) → Project Bidding Page Current Projects Summary Page → Project Detail Page (Post-Contract) → Room Detail Page → Room Suggestions Page
