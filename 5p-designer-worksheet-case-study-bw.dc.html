It’s time to pick up the role of a Senior Designer. Instead of wireframes, we’ll plan out what would go on each page. Using the user story as a reference, decide which page it will go on, the call to action, and the information to be displayed on the page. I filled in some examples for the homeowner and contractor and left some extra blank ones for you to add your own user stories.
