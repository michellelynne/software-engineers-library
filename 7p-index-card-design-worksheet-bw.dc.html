Here is the exercise worked through for the case study, using the contractor’s first run through the app.

How to run the test
1Draw each page on a single index card. Use the case study Page Flows.
2If you need more room, such as a scroll or a popup, add a new card. Collect them into a deck.
3Try to find a test user you haven’t told about the app. Write down what interacting with the card does so you know what to do, but don’t share it with users.
4Hand them a single home screen card with the instruction: “Treat this like an app.”
5Record the session if they’ll let you. If not, take detailed notes of where they look and interact with the cards.
6If they click, swipe, pinch or zoom, hand them the card for that page. If you don’t have a card for what they do, mark that as an error.
7Don’t interrupt or give them any help, since a real visitor gets none either.
8Repeat the test with new cards as long as they’ll let you. With index cards, you can quickly add and remove.
